# Neon Escape

A fast-paced browser survival arcade game built with Next.js and TypeScript.

## Play

Move with **WASD / Arrow Keys**. Collect energy orbs, avoid hunters, build your combo, and use **Space** to phase through danger when you have enough energy.

The Grid evolves as your survival time increases.

## Features

- Responsive canvas gameplay
- Progressive waves and enemy scaling
- Chaser, hunter, and orbiting enemy behaviors
- Energy collection and Phase ability
- Combo-based scoring
- Local high score persistence
- Pause and restart flow
- Keyboard controls
- No account required

## Development

```bash
npm install
npm run dev
```

Then open the local development URL shown by Next.js.
